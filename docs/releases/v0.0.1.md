# v0.0.1 — Agent Ops: nền tảng theo dõi và duyệt việc cho đội agent bán hàng

Ngày phát hành: 30/10/2026 · Tag: `v0.0.1` · Web app: https://danny-exnodes.github.io/my-agentic-ennam/

Bản đầu tiên của repo. Gồm hai phần: **quy trình đội agent bán hàng** (skill, luật, hồ sơ công ty) và **Agent Ops**, một hệ thống độc lập có database, đăng nhập, theo dõi agent trên cloud lẫn máy local, theo dõi routine và hàng đợi Duyệt.

## Điểm chính
- **Quy trình bán hàng** cho Exnodes và Én Nam, ưu tiên thị trường Úc: `sales-workflow`, `prospecting`, `outreach`, `follow-up`, `daily-report`, `ops-status` trong `.claude/skills/`.
- **Luật của Danny** trong `memory/rules.md`:
  - hỏi trước khi email cho người đã có trong Gmail;
  - giữ lại nhóm khách childcare, không liên hệ;
  - mọi email dùng chữ ký Gmail và cc 3 người;
  - không bịa số liệu;
  - repo public nên không chứa dữ liệu khách.
- **Agent Ops trên Supabase:**
  - Postgres có row level security và 3 vai trò: owner, approver, viewer;
  - Edge Function `agent-api`, mỗi agent một token riêng (lưu dạng sha256);
  - Realtime cho web app.
- **Báo trạng thái tự động:** hook Claude Code (SessionStart, PostToolUse, Stop, SessionEnd) gọi `scripts/agentops.py`, chỉ dùng thư viện chuẩn Python. Heartbeat gửi tối đa mỗi 60 giây. Agent quá 15 phút không có tín hiệu hiện "Mất kết nối".
- **Theo dõi routine:** routine báo đã chạy bằng `routine-start`, lịch được đồng bộ bằng `schedules-sync`. View `v_schedules` phát hiện lỡ lịch (quá `grace_minutes`) và lần chạy trước lỗi.
- **Hàng đợi Duyệt:**
  - agent đề xuất gửi email, follow-up hoặc việc cần người làm;
  - Danny duyệt hoặc từ chối (kèm lý do) trên web;
  - agent gửi email đã duyệt rồi ghi kết quả;
  - trigger chặn sửa nội dung sau khi đã duyệt, chặn người dùng tự đánh dấu "đã thực hiện".
- **Web app** trên GitHub Pages:
  - đăng nhập bằng magic link;
  - các tab Tổng quan, Duyệt, Agents, Routines, Pipeline, Prospects, Nhật ký, Cài đặt;
  - owner tạo và thu hồi token, quản lý người dùng;
  - xem trước email trong iframe sandbox;
  - hiển thị được trên điện thoại.

|---|---|---|
| `ci.yml` | mọi push và PR | test PGlite, biên dịch script Python, kiểm tra `site/`, `node --check` |
| `pages.yml` | push `main` đổi `site/` | deploy web app lên Pages |
| `supabase.yml` | push `main` đổi `supabase/` | `db push` và deploy `agent-api`; bỏ qua khi chưa có secret |
